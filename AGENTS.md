# MinerData - Agentes

## Comandos

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Faz o build de produção
- `npm run lint` - Verifica o código com ESLint
- `npm run db:setup` - Cria a tabela no banco local
- `npm run db:seed` - Popula o banco com minerais de exemplo
- `npm run db:push` - Sincroniza schema com Turso via Drizzle

## Stack

- Next.js 16 (App Router)
- Tailwind CSS v4
- Turso (libSQL/SQLite)
- Drizzle ORM
- NextAuth v5 (beta)
- Vercel Blob (upload de imagens)
